# Chronovisor — Evidence Reconstruction Lab

**Explore online:** [Open the public browser experience](https://luckygithub777.github.io/chronovisor-evidence-lab/). Explore the fictional evidence reconstruction in your browser; no local server is required for the hosted edition.

A dependency-free browser experience for exploring how **known, inferred, possible, and unknown** evidence affects a hypothetical reconstruction.

## Explore

The fixed **Pompeii — AD 79** example is illustrative, not a sourced archaeological dossier. Explore **RECONSTRUCT**, **EVIDENCE**, **TIMELINE**, and **DECIDE**. The timeline openly indicates when no dated records exist, and decision screens perform no outside action.

Run a local static server from the repository directory:

```bash
python -m http.server 8000
```

Open `http://127.0.0.1:8000/`. The browser loads the bundled JSON locally from this server; simply opening the HTML file may block that fetch. No account, telemetry, live research feed or claim of time observation is included.
